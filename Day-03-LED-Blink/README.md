# Day 03 – LED Blink Test

## Virtual Internship
**Organization:** Emertxe Information Technologies

## Objective
To understand how to control a digital output pin by blinking the onboard LED in a simulated Arduino environment.

## Platform
- PICSimLab (Arduino UNO Simulation)

## Software Used
- Arduino IDE
- PICSimLab

## Program Description
This program blinks the onboard LED continuously to verify digital output operation in the simulated Arduino UNO environment.

## Concepts Covered
- Digital Output
- pinMode()
- digitalWrite()
- delay()

## Expected Output
The onboard LED blinks continuously inside the PICSimLab simulation.

## Learning Outcome
This experiment helped me understand the fundamentals of Arduino programming and digital output control using a virtual simulation environment.
