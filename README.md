# Smart Factory Monitoring System

## Overview

Smart Factory Monitoring System is an IoT-based industrial monitoring project completed during the **Emertxe Virtual IoT Internship**.

This project was developed completely using simulation and virtual environments to understand Industrial IoT concepts, sensor data acquisition, MQTT communication and cloud telemetry.

No physical hardware was used during this internship.

## Technologies Used

- Arduino UNO (Simulation)
- Ethernet Shield (Simulation)
- MQTT Protocol
- ThingsBoard Cloud Platform
- DHT22 Temperature & Humidity Sensor
- LM35 Temperature Sensor
- Potentiometer (Analog Sensor)
- Embedded C Programming

---

## Project Modules

### Day 03
LED Blinking using Arduino GPIO.

### Day 04
Analog sensor reading using ADC and value mapping.

### Day 05
DHT22 sensor interfacing and millis() based real-time data reading.

### Day 06
MQTT communication using Ethernet Shield.

### Day 07
Sending telemetry data to ThingsBoard Cloud using MQTT.
