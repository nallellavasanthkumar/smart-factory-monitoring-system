# Day 07 - ThingsBoard Cloud Telemetry using MQTT

## Virtual Internship

**Project:** Smart Factory Monitoring System  
**Organization:** Emertxe Information Technologies

---

## Objective

To connect Arduino UNO with ThingsBoard Cloud using MQTT protocol and send telemetry data to the cloud dashboard.

---

## Components Used

- Arduino UNO
- Ethernet Shield
- MQTT Protocol
- ThingsBoard Cloud Platform

---

## Software and Libraries Used

- Arduino IDE
- SPI Library
- Ethernet Library
- PubSubClient Library

---

## Concepts Learned

- IoT Cloud Platform
- ThingsBoard Device Management
- MQTT Authentication
- Access Token
- Telemetry Data Transmission
- JSON Payload Format

---

## Working Principle

Arduino UNO connects to the internet using Ethernet Shield.

The MQTT client connects to the ThingsBoard MQTT broker using a device access token.

Sensor data is converted into JSON format and published to the ThingsBoard telemetry topic.
